## Accéder au module Contrats

Le module Contrats est accessible depuis la barre de navigation principale de Papaours.

### Étapes pour accéder aux contrats

1. Connectez-vous à votre compte Papaours
2. Dans la barre de navigation latérale, cliquez sur **Contrats**
3. Un sous-menu s'affiche avec deux options :
   - **Liste** : Accès aux contrats validés
   - **Brouillons de contrats** : Accès aux contrats en cours de création

---

## Liste des contrats validés

La page **Liste** affiche tous les contrats d'apprentissage validés auxquels vous avez accès selon vos droits.

### Informations affichées

Le tableau présente les colonnes suivantes :

| Colonne | Description |
|---------|-------------|
| **Apprenant** | Nom et prénom de l'apprenti avec sa photo |
| **Référence** | Code unique du contrat (ex: CA2026-000057) |
| **Session de formation** | Nom de la session de formation |
| **Unité de formation** | Site ou UFA de rattachement |
| **Employeur** | Nom de l'entreprise |
| **Date de conclusion** | Date de signature du contrat |
| **Période** | Dates de début et fin du contrat |
| **Version** | Version du format CERFA |
| **État** | Statut actuel (En cours, Signé, Rompu) |

### Actions disponibles

Pour chaque contrat, vous pouvez :

- **Voir** : Accéder à la fiche détaillée du contrat
- **Supprimer** : Supprimer le contrat (selon vos droits)

### Recherche et filtres

- **Barre de recherche** : Recherchez par référence, nom de l'apprenant, session, site de formation ou employeur
- **Bouton Filtres** : Accédez à des filtres avancés pour affiner votre recherche

### Pagination

La liste est paginée avec un sélecteur permettant de choisir le nombre d'éléments par page (10, 25, 50, 100).

---

## Liste des brouillons de contrats

La page **Brouillons de contrats** affiche tous les contrats en cours de création.

### Différences avec la liste des contrats validés

| Colonne | Liste des contrats | Brouillons |
|---------|-------------------|------------|
| État | En cours / Signé / Rompu | - |
| Complétion | - | Pourcentage (20% à 100%) |
| Actions | Voir / Supprimer | Voir / Compléter |

### Actions disponibles sur les brouillons

- **Voir** : Accéder au récapitulatif du brouillon
- **Compléter** : Reprendre la saisie du brouillon
