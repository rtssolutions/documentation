## Lien entre contrat et financement

Le contrat d'apprentissage est la base du dossier de financement. Une fois le contrat validé, vous pouvez créer un dossier de financement pour obtenir la prise en charge par l'OPCO.

---

## Lancer le financement

### Depuis la fiche contrat

1. Accédez à la fiche du contrat validé
2. Cliquez sur le bouton **Financer le contrat**
3. Vous êtes redirigé vers le parcours de création du dossier de financement

### Prérequis

Pour pouvoir financer un contrat :

- Le contrat doit être **validé** (pas un brouillon)
- L'état du contrat doit être **En cours** ou **Signé**
- Un contrat **Rompu** ne peut pas être financé

---

## Parcours de financement

Le parcours de financement est détaillé dans la documentation du module **Financement**. Il comprend notamment :

1. **Informations générales** : Catégorie de financement, financeur/OPCO
2. **Période de financement** : Dates de prise en charge
3. **Accompagnement RQTH** : Si l'apprenti a une RQTH
4. **Ventilation des prestations** : Répartition par financeur
5. **Récapitulatif** : Validation du dossier

---

## Informations reprises du contrat

Le dossier de financement reprend automatiquement les informations du contrat :

| Donnée | Source |
|--------|--------|
| Apprenant | Contrat |
| Employeur | Contrat |
| OPCO | Employeur (via le contrat) |
| Session de formation | Contrat |
| Dates du contrat | Contrat |
| Rémunération | Contrat |

Cela évite la double saisie et garantit la cohérence des données.
