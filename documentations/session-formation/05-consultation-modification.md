# Consulter et modifier une session de formation

## Accéder à la fiche d'une session

1. Menu **Formations** > **Sessions de formation**
2. Cliquez sur la session souhaitée dans la liste

## Informations affichées

### En-tête

L'en-tête présente les informations principales :

- **Intitulé** de la session
- **Formation** et **unité** associées
- **Dates** de début et fin
- **Statut** de la session
- **Remplissage** (inscrits / capacité)
- **Boutons d'action** (modifier, approuver, etc.)

### Onglets disponibles

| Onglet | Contenu |
|--------|---------|
| **Informations** | Détails de la session |
| **Apprenants** | Liste des dossiers de formation rattachés |
| **Documents** | Documents rattachés à la session |

## Onglet Informations

Cet onglet affiche :

| Section | Description |
|---------|-------------|
| **Action de formation** | Lien vers la fiche action |
| **Dates** | Période de formation |
| **Capacité** | Places disponibles et remplissage |
| **Paramètres** | Informations complémentaires |

## Onglet Apprenants

Liste des dossiers de formation rattachés à cette session :

| Information | Description |
|-------------|-------------|
| **Apprenant** | Nom et prénom |
| **Employeur** | Entreprise d'accueil |
| **Contrat** | Type et statut du contrat |
| **Dossier** | État du dossier de formation |

Depuis cet onglet, vous pouvez :

- **Consulter** un dossier en cliquant sur la ligne
- **Ajouter** un apprenant (rattacher un dossier existant)
- **Retirer** un apprenant de la session

## Modifier une session

### Accès à la modification

1. Ouvrez la fiche de la session
2. Cliquez sur **Modifier**
3. Le formulaire de modification s'affiche

### Champs modifiables

| Champ | Modifiable | Remarque |
|-------|------------|----------|
| **Action de formation** | Non | Liée définitivement |
| **Date de début** | Oui | Avec restrictions si apprenants inscrits |
| **Date de fin** | Oui | Avec restrictions si apprenants inscrits |
| **Intitulé** | Oui | Nom de la session |
| **Capacité** | Oui | Ne peut pas être inférieure aux inscrits |
| **Commentaires** | Oui | Notes libres |

### Enregistrer les modifications

1. Effectuez vos modifications
2. Cliquez sur **Enregistrer**
3. Les modifications sont appliquées immédiatement

## Inscrire un apprenant

### Depuis l'onglet Apprenants

1. Cliquez sur **Ajouter un apprenant**
2. Recherchez le dossier de formation à rattacher
3. Sélectionnez le dossier
4. Confirmez l'inscription

### Prérequis

- Le dossier de formation doit correspondre à la même formation
- La session doit avoir des places disponibles
- La session doit être approuvée

## Retirer un apprenant

1. Dans l'onglet **Apprenants**, identifiez la ligne
2. Cliquez sur l'action **Retirer**
3. Confirmez le retrait

Le dossier de formation n'est pas supprimé, il est simplement détaché de cette session.
