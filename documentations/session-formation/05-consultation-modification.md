# Consulter et modifier une session de formation

## Accéder à la fiche d'une session

1. Menu **Formations** > **Sessions de formation**
2. Cliquez sur la session souhaitée dans la liste

## Informations affichées

### En-tête

L'en-tête présente les informations principales :

- **Intitulé** de la session
- **Formation** et **unité** associées
- **Dates** de début et fin
- **Boutons d'action** (modifier, etc.)

### Onglets disponibles

| Onglet | Contenu |
|--------|---------|
| **Informations** | Détails de la session |
| **Documents** | Documents rattachés à la session |

## Onglet Informations

Cet onglet affiche :

| Section | Description |
|---------|-------------|
| **Action de formation** | Lien vers la fiche action |
| **Dates** | Période de formation |
| **Paramètres** | Informations complémentaires |

## Modifier une session

### Accès à la modification

1. Ouvrez la fiche de la session
2. Cliquez sur **Modifier**
3. Le formulaire de modification s'affiche

### Champs modifiables

| Champ | Modifiable | Remarque |
|-------|------------|----------|
| **Action de formation** | Non | Liée définitivement |
| **Date de début** | Oui | |
| **Date de fin** | Oui | |
| **Intitulé** | Oui | Nom de la session |
| **Commentaires** | Oui | Notes libres |

### Enregistrer les modifications

1. Effectuez vos modifications
2. Cliquez sur **Enregistrer**
3. Les modifications sont appliquées immédiatement

## Maillage avec les dossiers de formation

Le lien entre une session et les apprenants se fait via le **maillage** des dossiers de formation. Cette opération se réalise depuis le module [Dossier de formation](../dossier-formation/index).
