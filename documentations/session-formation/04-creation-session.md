# Créer une session de formation

## Prérequis

Avant de créer une session de formation, assurez-vous que :

- L'**action de formation** existe et est approuvée
- Vous disposez des **droits** nécessaires à la création

## Accéder à la création

### Méthode 1 : Depuis la liste des sessions

1. Menu **Formations** > **Sessions de formation**
2. Cliquez sur **Nouvelle session de formation**

### Méthode 2 : Depuis une action de formation

1. Accédez à la fiche de l'action de formation
2. Onglet **Sessions**
3. Cliquez sur **Ajouter une session**

L'action de formation est automatiquement pré-sélectionnée.

## Formulaire de création

### Informations obligatoires

| Champ | Description |
|-------|-------------|
| **Action de formation** | Sélectionnez l'action de formation |
| **Date de début** | Premier jour de la session |
| **Date de fin** | Dernier jour de la session |

### Informations recommandées

| Champ | Description |
|-------|-------------|
| **Intitulé** | Nom de la session (ex: "Promotion 2024-2026") |
| **Capacité** | Nombre maximum d'apprenants |

### Informations optionnelles

| Champ | Description |
|-------|-------------|
| **Code interne** | Référence interne de la session |
| **Commentaires** | Notes complémentaires |

## Validation des dates

Les règles suivantes s'appliquent :

- La date de fin doit être postérieure à la date de début
- Les dates doivent être cohérentes avec le calendrier pédagogique
- Les chevauchements avec d'autres sessions sont autorisés

## Validation

1. Vérifiez les informations saisies
2. Cliquez sur **Créer**
3. La session est créée avec le statut **À approuver**

## Après la création

La session de formation créée doit être approuvée avant de pouvoir :

- Inscrire des apprenants (rattacher des dossiers de formation)
- Être utilisée dans les plannings

Consultez [Processus d'approbation](06-processus-approbation) pour plus de détails.

## Erreurs courantes

### "Action de formation non approuvée"

L'action de formation sélectionnée n'est pas encore approuvée. Approuvez d'abord l'action avant de créer la session.

### "Dates incohérentes"

La date de fin est antérieure ou égale à la date de début. Corrigez les dates saisies.

### "Capacité insuffisante"

La capacité saisie est inférieure au nombre d'apprenants déjà pré-inscrits (cas rare lors de migrations).
