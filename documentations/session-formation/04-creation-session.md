# Créer une session de formation

## Prérequis

Avant de créer une session de formation, assurez-vous que :

- L'**action de formation** existe
- Vous disposez des **droits** nécessaires à la création

## Accéder à la création

La création de session se fait **depuis une action de formation** :

1. Accédez à la fiche de l'action de formation
2. Onglet **Sessions**
3. Cliquez sur **Ajouter une session**

L'action de formation est automatiquement pré-sélectionnée.

## Formulaire de création

### Informations obligatoires

| Champ | Description |
|-------|-------------|
| **Action de formation** | Pré-sélectionnée |
| **Date de début** | Premier jour de la session |
| **Date de fin** | Dernier jour de la session |

### Informations optionnelles

| Champ | Description |
|-------|-------------|
| **Intitulé** | Nom de la session (ex: "Promotion 2024-2026") |
| **Code interne** | Référence interne de la session |
| **Commentaires** | Notes complémentaires |

## Validation des dates

Les règles suivantes s'appliquent :

- La date de fin doit être postérieure à la date de début
- Les chevauchements avec d'autres sessions sont autorisés

## Validation

1. Vérifiez les informations saisies
2. Cliquez sur **Créer**
3. La session est créée

## Après la création

Une fois la session créée, vous pouvez :

- Mailler des dossiers de formation à cette session
- Consulter et modifier ses paramètres

## Erreurs courantes

### "Dates incohérentes"

La date de fin est antérieure ou égale à la date de début. Corrigez les dates saisies.
