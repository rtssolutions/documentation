# Session de formation

Le module **Session de formation** permet de gérer les périodes de formation programmées. Une session représente une instance concrète d'une action de formation, avec des dates précises.

## Fonctionnalités principales

- Création de sessions rattachées à une action de formation
- Planification des dates de début et fin
- Maillage avec les dossiers de formation
