# Accéder à la gestion des sessions de formation

## Accès au module

### Depuis le menu principal

1. Cliquez sur **Formations** dans le menu latéral
2. Sélectionnez **Sessions de formation**

### Depuis une action de formation

1. Accédez à la fiche d'une action de formation
2. Consultez l'onglet **Sessions**
3. Vous voyez la liste des sessions rattachées

### Depuis une formation

1. Accédez à la fiche d'une formation
2. Consultez l'onglet **Sessions**
3. Vous voyez toutes les sessions de cette formation (toutes unités confondues)

## Interface de liste

La liste des sessions de formation affiche :

| Colonne | Description |
|---------|-------------|
| **Intitulé** | Nom de la session ou de la formation |
| **Dates** | Période de formation |
| **Unité** | Site dispensateur |

## Filtres disponibles

Utilisez les filtres pour affiner votre recherche :

- **Formation** : filtrer par formation
- **Unité de formation** : filtrer par site
- **Période** : sessions en cours, à venir, terminées

## Recherche

La barre de recherche permet de trouver une session par :

- Nom de la formation
- Nom de l'unité de formation

## Actions depuis la liste

Depuis la liste, vous pouvez :

- **Consulter** : cliquer sur une session pour voir le détail

La création de session ne se fait pas depuis la liste mais depuis une action de formation.
