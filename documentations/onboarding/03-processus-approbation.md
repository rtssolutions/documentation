# Processus d'approbation

## Principe

Lors de l'onboarding, les **unités de formation** importées doivent être approuvées avant d'être utilisables dans Papaours. Ce processus garantit la qualité et la conformité de vos données.

## Éléments concernés

Le processus d'approbation s'applique uniquement aux :

| Élément | Description | Documentation détaillée |
|---------|-------------|------------------------|
| **Unités de formation** | Sites ou UFA dispensant les formations | [Module Unité de formation](../unite-formation/08-processus-approbation) |

## Statuts

Chaque unité de formation passe par un statut d'approbation :

- **À approuver** : en attente de validation
- **Approuvée** : validée et active dans le système

## Pré-alimentation automatique

Lors de l'onboarding, Papaours détecte et pré-alimente automatiquement les unités de formation depuis le référentiel national. Ces unités sont placées en statut "À approuver" pour validation par l'administrateur.
