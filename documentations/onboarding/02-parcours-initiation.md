# Parcours d'initiation

## Vue d'ensemble

Le parcours d'initiation vous guide pas à pas dans la configuration de votre environnement Papaours. Il s'assure que toutes les informations essentielles sont renseignées avant de commencer à utiliser pleinement la plateforme.

## Étapes du parcours

### Étape 1 : Création du centre de formation

La première étape consiste à créer et configurer votre centre de formation :

1. **Informations d'identification**
   - Dénomination sociale
   - Numéro SIRET
   - Code UAI (si applicable)

2. **Coordonnées**
   - Adresse du siège
   - Téléphone et email de contact
   - Site internet

3. **Informations complémentaires**
   - Type d'organisme
   - Numéro de déclaration d'activité

### Étape 2 : Désignation de l'administrateur

Associez un administrateur principal à votre centre de formation :

- **Informations de l'administrateur** : nom, prénom, email
- **Rôle attribué** : Administrateur Centre de Formation
- **Permissions** : accès complet à la gestion du centre

### Étape 3 : Contrôle de cohérence

Le système vérifie automatiquement la cohérence des données saisies :

- **Validation du SIRET** : vérification auprès du référentiel INSEE
- **Cohérence des dates** : vérification des périodes
- **Complétude des informations** : identification des champs obligatoires manquants

## Pré-alimentation automatique

Papaours détecte et alimente automatiquement certaines données :

- **Formations** : récupération depuis le référentiel national (RNCP)
- **Unités de formation** : identification des organismes partenaires
- **Actions de formation** : création des actions associées

Ces éléments sont placés dans le module d'approbation pour validation.
