## Accéder à la liste des formations

1. Depuis la barre de navigation, cliquez sur **Formations**
2. Dans le sous-menu, cliquez sur **Formations**

La page affiche la liste de toutes les formations de votre catalogue.

---

## Liste des formations

### Informations affichées

Le tableau présente les colonnes suivantes :

| Colonne | Description |
|---------|-------------|
| **Intitulé** | Nom de la formation |
| **Référence** | Code unique (ex: FOR2026-000016) |
| **Diplôme** | Intitulé du diplôme |
| **Certification** | Code RNCP |
| **Durée théorique** | Durée prévue |

### Actions disponibles

Pour chaque formation :
- **Voir** : Accéder à la fiche détaillée
- **Modifier** : Éditer les informations
- **Supprimer** : Supprimer la formation (selon droits)

### Recherche

La barre de recherche permet de filtrer par :
- Code RNCP
- Diplôme
- Intitulé de la formation

---

## Créer une formation

1. Cliquez sur le bouton **Créer une formation**
2. Recherchez la formation dans le référentiel national (RNCP)
3. Sélectionnez la formation souhaitée
4. Complétez les informations spécifiques à votre établissement
5. Validez la création

### Importation de formations

Si des formations sont en attente d'importation (issues d'une synchronisation avec les référentiels nationaux), une alerte s'affiche en haut de la liste :

> "X Formation(s) en attente d'importation"

Cliquez sur **Finaliser l'importation** pour valider l'ajout de ces formations à votre catalogue.

---

## Consulter une formation

La fiche formation présente plusieurs sections :

### Informations générales

- Référence de la formation
- Intitulé commercial
- Voies d'accès (Apprentissage, Continue, VAE, Initiale, etc.)
- Durée théorique
- Volume d'heures
- Formation en distanciel (Oui/Non)
- Heures en distanciel
- Taux de formation à distance

### Actions de formation

Liste des actions de formation rattachées, avec :
- Nom de la formation
- Unité de formation qui la dispense
- Lien pour créer une nouvelle action de formation

### Certification

Informations sur la certification RNCP :
- Code RNCP avec lien vers la fiche officielle
- État (Active/Inactive)
- Intitulé de la certification
- Date d'échéance
- Niveau de qualification

### Diplôme

Informations sur le diplôme :
- Intitulé court et complet
- Diplôme ou titre visé
- Niveau de formation
- Code diplôme
- Code MEF (si applicable)

### Documents associés

Section permettant de :
- **Ajouter un document** : Téléverser un fichier
- **Générer un document** : Créer un document à partir d'un modèle
- Rechercher et consulter les documents existants

### Historique des actions

Trace des modifications effectuées sur la formation.

---

## Modifier une formation

1. Depuis la liste, cliquez sur **Modifier** ou depuis la fiche, cliquez sur **Modifier les informations**
2. Modifiez les champs souhaités
3. Enregistrez les modifications

---

## Supprimer une formation

1. Cliquez sur le bouton **Supprimer**
2. Confirmez la suppression

La suppression n'est possible que si la formation n'est pas utilisée (pas d'action de formation, pas de session active).
