## Gérer les représentants légaux

### Accéder à la section Représentants légaux

1. Accédez à la fiche d'un apprenant via **Apprenants > Liste**
2. Cliquez sur **Voir** pour ouvrir le détail de l'apprenant
3. Faites défiler jusqu'à la section **Représentants légaux**

La section affiche un tableau avec tous les représentants légaux associés à l'apprenant.

![Section représentants légaux](https://papaours.s3.fr-par.scw.cloud/documentations/tutoriel/apprenant/05-section-representants-legaux.png "800x450")

### Colonnes du tableau

| Colonne | Description |
|---------|-------------|
| **Représentant** | Nom, prénom et adresse email |
| **Téléphone** | Numéro de téléphone |
| **Adresse** | Adresse postale |
| **Rôle** | Type de relation (Père, Mère, Tuteur, etc.) |
| **Signataire** | Oui/Non - indique si ce représentant signe les documents |

### Ajouter un représentant légal

1. Cliquez sur le bouton **Ajouter un représentant**
2. Remplissez le formulaire :
   - Civilité, Nom et Prénom
   - Adresse email
   - Numéro de téléphone
   - Adresse postale
   - Rôle (Père, Mère, Tuteur, Curateur, Autre)
   - Case à cocher "Signataire" si ce représentant doit signer les documents
3. Validez pour enregistrer

![Formulaire d'ajout d'un représentant légal](https://papaours.s3.fr-par.scw.cloud/documentations/tutoriel/apprenant/06-ajout-representant-legal.png "800x450")

### Modifier un représentant légal

1. Dans le tableau, localisez le représentant à modifier
2. Cliquez sur le bouton **Modifier**
3. Effectuez les modifications souhaitées
4. Validez pour enregistrer

![Formulaire de modification d'un représentant légal](https://papaours.s3.fr-par.scw.cloud/documentations/tutoriel/apprenant/04-representant-legal-modification.png "800x450")

### Consulter un représentant légal

1. Dans le tableau, localisez le représentant concerné
2. Cliquez sur le bouton **Voir** pour afficher le détail complet

### Supprimer un représentant légal

1. Dans le tableau, localisez le représentant à supprimer
2. Cliquez sur le bouton **Supprimer**
3. Confirmez la suppression

**Attention** : La suppression d'un représentant légal peut impacter les contrats en cours si ce représentant est désigné comme signataire.

## Cas particuliers

### Apprenant sous curatelle ou tutelle

Si la case **Sous curatelle ou tutelle** est cochée dans la fiche apprenant, vous devez obligatoirement renseigner un représentant légal avec le rôle approprié (Tuteur ou Curateur).

### Apprenant émancipé

Un apprenant mineur peut être **émancipé** (décision judiciaire lui conférant la capacité juridique d'un majeur). Dans ce cas :

- La case **Apprenant émancipé(e)** peut être cochée
- Aucun représentant légal n'est requis pour la signature des documents

### Plusieurs représentants légaux

Il est possible d'ajouter plusieurs représentants légaux pour un même apprenant. Cependant, un seul représentant peut être désigné comme **signataire** pour les documents officiels (CERFA).
