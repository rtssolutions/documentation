# Historique

Le module **Historique** permet de consulter toutes les actions réalisées par les utilisateurs sur les différentes entités de la plateforme Papaours (apprenants, contrats, formations, etc.).

Cette fonctionnalité assure une **traçabilité complète** des modifications, utile pour l'audit, le suivi et la compréhension de l'état actuel des données.
