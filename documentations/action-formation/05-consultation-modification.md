# Consulter et modifier une action de formation

## Accéder à la fiche d'une action

1. Depuis la fiche d'une **formation** ou d'une **unité de formation**
2. Dans la section **Actions de formation**, cliquez sur l'action souhaitée

![Fiche détaillée d'une action de formation](https://papaours.s3.fr-par.scw.cloud/documentations/tutoriel/action-formation/03-fiche-action-formation.png "800x450")

## Informations affichées

### En-tête

L'en-tête présente les informations principales :

- **Intitulé** de la formation
- **Unité de formation** associée
- **Boutons d'action** (modifier, etc.)

### Onglets disponibles

| Onglet | Contenu |
|--------|---------|
| **Informations** | Détails de l'action et paramètres |
| **Sessions** | Liste des sessions associées |
| **Documents** | Documents rattachés à l'action |

## Onglet Informations

Cet onglet affiche :

| Section | Description |
|---------|-------------|
| **Formation** | Lien vers la fiche formation |
| **Unité de formation** | Lien vers la fiche unité |
| **Lieux de formation** | Lieu principal et lieux secondaires |
| **Dates** | Date de création et dernière modification |

## Onglet Sessions

Liste des sessions rattachées à cette action :

- Dates de début et fin
- Intitulé de la session

Depuis cet onglet, vous pouvez :

- **Consulter** une session en cliquant dessus
- **Créer** une nouvelle session

## Modifier une action

### Accès à la modification

1. Ouvrez la fiche de l'action
2. Cliquez sur **Modifier les informations**
3. Le formulaire de modification s'affiche

![Formulaire de modification d'une action de formation](https://papaours.s3.fr-par.scw.cloud/documentations/tutoriel/action-formation/09-modification-action.png "800x450")

### Champs modifiables

| Champ | Modifiable | Remarque |
|-------|------------|----------|
| **Formation** | Non | Liée définitivement |
| **Unité de formation** | Non | Liée définitivement |
| **Lieu principal** | Oui | Peut différer de l'unité |
| **Lieux secondaires** | Oui | Peuvent être ajoutés/retirés |
| **Code interne** | Oui | Référence interne |
| **Commentaires** | Oui | Notes libres |

### Modifier les lieux de formation

Les lieux de formation hérités de l'unité peuvent être personnalisés :

1. Sur la fiche de l'action, cliquez sur **Modifier les lieux de formation**
2. L'écran de gestion des lieux s'affiche
3. Modifiez le lieu principal ou les lieux secondaires
4. Cliquez sur **Enregistrer les modifications**

![Modification des lieux de formation](https://papaours.s3.fr-par.scw.cloud/documentations/tutoriel/action-formation/10-modification-lieux.png "800x450")

Cette personnalisation permet d'adapter les lieux selon les spécificités de chaque formation dispensée.

### Enregistrer les modifications

1. Effectuez vos modifications
2. Cliquez sur **Enregistrer**
3. Les modifications sont appliquées immédiatement

## Créer une session depuis l'action

1. Accédez à l'onglet **Sessions**
2. Cliquez sur **Nouvelle session**
3. Le formulaire de création de session s'ouvre, pré-rempli avec l'action

Consultez [Module Sessions de formation](../session-formation/index) pour plus de détails.
