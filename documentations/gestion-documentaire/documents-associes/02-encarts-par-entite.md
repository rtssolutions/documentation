# Encarts par entité

## Vue d'ensemble

Chaque entité principale de Papaours dispose d'un ou plusieurs encarts pour gérer les documents associés. Cette page détaille l'emplacement et le contenu de ces encarts.

---

## Apprenant

### Emplacement

L'encart documents de l'apprenant se trouve dans la fiche de consultation, accessible via :

1. Menu **Apprenants**
2. Sélection d'un apprenant
3. Section **Documents** dans le panneau de détails

### Types de documents

| Type | Description | Usage |
|------|-------------|-------|
| **Pièce d'identité** | CNI, passeport, titre de séjour | Identification |
| **Justificatif de domicile** | Facture, attestation d'hébergement | Adresse |
| **Diplômes** | Copies des diplômes obtenus | Parcours antérieur |
| **CV** | Curriculum vitae | Profil professionnel |

### Documents des besoins spécifiques

Les apprenants présentant des besoins spécifiques disposent d'un encart dédié :

- **Attestation RQTH** : reconnaissance de travailleur handicapé
- **Certificat sportif** : sportif de haut niveau
- **Aménagements** : justificatifs d'aménagements pédagogiques

> Ces documents sont particulièrement sensibles et bénéficient de permissions spécifiques.

## Employeur

### Emplacement

L'encart documents de l'employeur se trouve dans la fiche employeur :

1. Menu **Employeurs**
2. Sélection d'un employeur
3. Section **Documents** dans le panneau de détails

### Types de documents

| Type | Description | Usage |
|------|-------------|-------|
| **Extrait Kbis** | Immatriculation de l'entreprise | Identification légale |
| **Attestation URSSAF** | Situation sociale de l'entreprise | Conformité |
| **Convention collective** | Document de la convention applicable | Référence |
| **Attestation d'assurance** | Responsabilité civile professionnelle | Couverture |

---

## Contrat

### Emplacement

L'encart documents du contrat se trouve dans la fiche contrat :

1. Menu **Contrats**
2. Sélection d'un contrat
3. Onglet **Documents**

### Types de documents

| Type | Description | Usage |
|------|-------------|-------|
| **CERFA FA13** | Formulaire officiel du contrat | Déclaration |
| **Contrat signé** | Version signée du contrat | Archive légale |
| **Avenants** | Modifications du contrat initial | Suivi |
| **Attestations** | Documents générés | Justificatifs |

### Documents générés automatiquement

Certains documents sont générés automatiquement par Papaours et apparaissent dans cet encart :

- **CERFA FA13** : généré lors de la validation du contrat
- **Documents de signature** : versions signées électroniquement

---

## Dossier de formation

### Emplacement

L'encart documents du dossier de formation se trouve dans la fiche dossier :

1. Menu **Dossiers de formation**
2. Sélection d'un dossier
3. Section **Documents**

### Types de documents

| Type | Description | Usage |
|------|-------------|-------|
| **CERFA P2S** | Prise en charge Pôle emploi | Financement |
| **Convention de formation** | Convention tripartite | Engagement |
| **Attestation d'inscription** | Preuve d'inscription | Justificatif |
| **Relevé de notes** | Résultats des évaluations | Suivi pédagogique |
| **Attestation de fin de formation** | Document de fin de parcours | Certification |

---

## Centre de formation

### Emplacement

L'encart documents du centre de formation se trouve dans les paramètres :

1. Menu **Paramètres**
2. **Centre de formation**
3. Section **Documents**

### Types de documents

| Type | Description | Usage |
|------|-------------|-------|
| **Déclaration d'activité** | Numéro DA | Conformité |
| **Certification Qualiopi** | Attestation de certification | Qualité |
| **Règlement intérieur** | Document interne | Gouvernance |
| **Conditions générales** | CGV / CGU | Contractuel |
