# Ajouter un document

## Prérequis

Avant d'ajouter un document, assurez-vous de :

- Disposer des **droits d'écriture** sur l'entité concernée
- Avoir le fichier à téléverser sur votre ordinateur
- Respecter les **formats acceptés** et la **taille maximale**

## Formats et tailles acceptés

### Formats supportés

| Type | Extensions | Usage typique |
|------|------------|---------------|
| **Documents** | PDF, DOC, DOCX | Contrats, attestations |
| **Images** | JPG, JPEG, PNG | Pièces d'identité scannées |
| **Tableurs** | XLS, XLSX | Tableaux, budgets |

### Taille maximale

- **Par fichier** : 10 Mo maximum
- **Recommandation** : compresser les fichiers volumineux avant téléversement

## Procédure d'ajout

### Étape 1 : Accéder à l'encart Documents

1. Ouvrez la fiche de l'entité concernée (Apprenant, Employeur, Contrat, etc.)
2. Naviguez vers la section **Documents** ou l'onglet **Documents associés**
3. Localisez le bouton **"Ajouter un document"**

### Étape 2 : Sélectionner le fichier

1. Cliquez sur **"Ajouter un document"**
2. Une fenêtre de sélection de fichier s'ouvre
3. Parcourez votre ordinateur et sélectionnez le fichier souhaité
4. Cliquez sur **"Ouvrir"**

### Étape 3 : Renseigner les informations

Selon le contexte, vous pouvez être invité à renseigner :

| Champ | Description | Obligatoire |
|-------|-------------|-------------|
| **Nom du document** | Intitulé affiché | Parfois |
| **Type de document** | Catégorie (pièce d'identité, justificatif, etc.) | Selon entité |
| **Description** | Commentaire libre | Non |
| **Date du document** | Date d'émission ou de validité | Selon type |

### Étape 4 : Valider le téléversement

1. Vérifiez les informations saisies
2. Cliquez sur **"Enregistrer"** ou **"Téléverser"**
3. Attendez la confirmation du téléversement
4. Le document apparaît dans la liste des documents associés

## Cas particuliers

### Documents des besoins spécifiques

Pour ajouter un document lié aux besoins spécifiques d'un apprenant :

1. Accédez à la fiche de l'apprenant
2. Ouvrez la section **Besoins spécifiques**
3. Dans la sous-section **Documents justificatifs**, cliquez sur **"Ajouter un document"**

> La permission spécifique "Écriture sur les documents des besoins spécifiques" est nécessaire.

### Remplacement d'un document

Pour remplacer un document existant :

1. Supprimez l'ancien document (si autorisé)
2. Ajoutez le nouveau document
3. Les deux versions sont conservées dans l'historique

## Bonnes pratiques

### Nommage des fichiers

Adoptez une convention de nommage claire :

```
[Type]_[Entité]_[Date].pdf
```

Exemples :
- `CNI_DUPONT_Jean_2024.pdf`
- `CERFA_FA13_CTR2025-000001.pdf`
- `Attestation_RQTH_2025.pdf`

### Organisation

- **Un document par fichier** : évitez de regrouper plusieurs documents
- **Documents à jour** : privilégiez les versions les plus récentes
- **Qualité de scan** : assurez-vous que les documents scannés sont lisibles

## Résolution de problèmes

### Le bouton "Ajouter" n'apparaît pas

- Vérifiez que vous disposez des droits d'écriture sur l'entité
- Contactez votre administrateur pour obtenir les permissions nécessaires

### Erreur lors du téléversement

- Vérifiez le format du fichier (doit être dans la liste des formats acceptés)
- Vérifiez la taille du fichier (max 10 Mo)
- Réessayez avec une connexion internet stable

### Le document n'apparaît pas après téléversement

- Actualisez la page (F5)
- Vérifiez dans l'historique que le téléversement a été enregistré
