# Mon profil

Le module **Mon profil** vous permet de gérer vos informations personnelles, consulter votre rattachement à un centre de formation, et gérer vos instances.

## Accéder à Mon profil

Cliquez sur votre nom ou votre photo de profil dans la barre de navigation latérale pour accéder à cette page.

---

## Structure de la page

La page Mon profil est organisée en plusieurs sections :

### En-tête

L'en-tête affiche :
- Votre **photo de profil** et votre **nom complet**
- Liens d'accès rapide :
  - **Modifier mes informations** : Accès au formulaire de modification
  - **Mes notifications** : Gestion de vos préférences de notification

### Mon centre

Cette section affiche les informations de votre centre de formation de rattachement :
- **Nom du centre** (ex: CFA Jean Bosco)
- **Adresse** du centre

Actions disponibles :
- **Modifier les informations** : Accéder aux paramètres du centre (selon vos droits)
- **Paramétrer les notifications** : Configurer les notifications au niveau du centre

### Vos instances

Si vous avez accès à plusieurs instances (environnements), un sélecteur vous permet de basculer entre elles.

---

## Informations personnelles

Le formulaire vous permet de modifier vos informations de contact :

| Champ | Description |
|-------|-------------|
| **Civilité** | Monsieur ou Madame |
| **Nom** | Votre nom de famille (obligatoire) |
| **Prénom** | Votre prénom (obligatoire) |
| **Courriel** | Votre adresse email (lecture seule, lié à votre compte) |
| **Téléphone** | Votre numéro de téléphone avec indicatif pays (obligatoire) |

### Modifier vos informations

1. Modifiez les champs souhaités
2. Cliquez sur **Sauvegarder**

Les modifications sont appliquées immédiatement.

---

## Déconnexion

En bas de la page, le lien **Déconnexion** vous permet de vous déconnecter de l'application. Vous serez redirigé vers la page de connexion.
